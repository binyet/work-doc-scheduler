# Work Doc Scheduler - 项目分析与实现计划

## 项目概述

Work Doc Scheduler 是一个基于 Electron 和 Vue 3 的桌面应用程序，用于管理工作文档的截止日期和状态。该应用提供了一个直观的日历界面，允许用户通过拖放方式将文档分配到特定日期，并跟踪文档的完成状态。

## 技术栈分析

### 前端技术
- **Vue 3**：使用 Composition API 进行组件开发
- **TypeScript**：提供类型安全
- **Element Plus**：提供 UI 组件
- **FullCalendar**：提供日历功能
- **dayjs**：处理日期时间
- **Pinia**：状态管理
- **mitt**：事件总线，用于组件间通信
- **vue-draggable-plus**：提供拖拽功能

### 后端技术
- **Electron**：提供桌面应用能力，包括文件系统操作
- **IndexedDB**：本地存储文档信息

## 核心功能分析

### 1. 日历视图
- **功能**：显示月度日历，标记文档的截止日期
- **实现**：使用 FullCalendar 组件，通过事件方式显示文档
- **交互**：支持日期点击选择，文件拖放，事件拖拽调整日期

### 2. 文档容器
- **功能**：显示当前选中日期的文档列表
- **实现**：使用 Vue Draggable 组件，支持拖拽排序
- **交互**：支持文件拖放添加，双击打开文件

### 3. 文件管理
- **功能**：添加、删除、标记完成文档
- **实现**：通过 IndexedDB 存储文档信息，Electron API 操作文件系统
- **交互**：右键菜单提供操作选项，支持文件移动到归档路径

### 4. 侧边栏控制
- **功能**：控制文档容器的显示/隐藏
- **实现**：通过状态管理和事件总线实现
- **交互**：点击箭头按钮切换状态

## 数据流分析

1. **文件添加**：
   - 用户拖放文件到日历或文档容器
   - 应用获取文件路径和信息
   - 创建 FileInfo 对象并存储到 IndexedDB
   - 更新日历视图和文档列表

2. **文件状态更新**：
   - 用户标记文档为完成
   - 应用调用 Electron API 移动文件到归档路径
   - 更新 IndexedDB 中的文件状态
   - 更新日历视图中的事件颜色

3. **文件删除**：
   - 用户通过右键菜单删除文档
   - 应用从 IndexedDB 中删除文件信息
   - 从日历视图中移除事件

## 项目结构分析

### 主要目录
- **src/components/**：包含日历、文档容器、右键菜单等组件
- **src/service/**：包含存储和数据服务
- **src/utils/**：工具函数
- **src/mitt/**：事件总线
- **electron/**：Electron 主进程和预加载脚本

### 核心文件
- **src/components/Calender/Index.vue**：日历组件，处理文件拖放和事件管理
- **src/components/WorkDocContainer/Index.vue**：文档容器，显示和管理文档列表
- **src/service/store/module/app.ts**：状态管理，处理文件信息和 Electron API 调用
- **src/service/db/indexedDb.ts**：IndexedDB 操作封装

## 技术难点与解决方案

### 1. 文件拖放功能
- **难点**：需要同时支持从系统拖放到应用，以及应用内部的拖拽
- **解决方案**：使用 FullCalendar 的 droppable 功能和 Vue Draggable 组件，结合自定义拖拽处理

### 2. 本地存储
- **难点**：需要可靠的本地存储方案
- **解决方案**：使用 IndexedDB 存储文档信息，提供持久化存储

### 3. Electron 集成
- **难点**：需要在 Vue 组件中调用 Electron API
- **解决方案**：通过预加载脚本暴露 Electron API，在 Vue 组件中通过状态管理调用

### 4. 日历与文档同步
- **难点**：确保日历视图和文档列表的数据同步
- **解决方案**：使用事件总线和状态管理，确保数据变更时及时更新视图

## 项目价值

Work Doc Scheduler 为用户提供了一个直观、高效的工作文档管理工具，通过日历视图和拖放操作，使用户能够轻松管理文档的截止日期和状态。该应用特别适合需要跟踪多个文档截止日期的用户，如学生、教师、办公室工作人员等。

通过本地存储和文件系统集成，应用提供了离线使用能力，确保用户数据的安全和隐私。同时，直观的界面设计和流畅的交互体验，使文档管理变得更加简单和高效。
